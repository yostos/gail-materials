== 内容

== 必要なもの

以下は自分でビルドする場合にのみ必要となる。読むだけなら <<ダウンロード>> から入手できる。

* Asciidoctor 2.0 以降
* Asciidoctor PDF 2.3 以降
* asciidoctor-diagram
* Rouge（ソースコードのシンタックスハイライト用）
* Python 3.8 以降（`scripts/md2adoc.py` を使う場合のみ）
* BIZ UDGothic の TTF。PDF に埋め込むため `build/fonts/` に配置する。取得方法は <<フォントの準備>> を見ること。

[source,console]
----
$ gem install asciidoctor asciidoctor-pdf asciidoctor-diagram rouge
----

=== フォントの準備

PDF には日本語フォントの埋め込みが必要になる。asciidoctor-pdf が同梱するフォントのうち
日本語を持つのは M+ 1p Fallback の Regular だけで、太字がすべて擬似ボールドになるため、
link:https://fonts.google.com/specimen/BIZ+UDGothic[BIZ UDGothic] を別途取得して使う。

[source,console]
----
$ make fonts
----

link:https://github.com/google/fonts[google/fonts] のコミットを固定して次の3ファイルを
`build/fonts/` に置く。取得物であってソースではないため、Git の管理対象外である。

[cols="2,3", options="header"]
|===
| ファイル | 用途

| `BIZUDGothic-Regular.ttf` | 本文
| `BIZUDGothic-Bold.ttf` | 太字・見出し
| `OFL.txt` | SIL Open Font License 1.1 の本文
|===

コード（`+[source]+` ブロックと `+`...`+`）は asciidoctor-pdf 同梱の M+ 1mn を使うため、
追加の取得は不要である。

== ビルド

[source,console]
----
$ make            # ヘルプを表示
$ make fonts      # PDF 用のフォントを build/fonts に取得
$ make all        # 全体の PDF と HTML を生成
$ make pdf        # 全体の PDF のみ
$ make html       # 全体の HTML のみ
$ make pdf-c3     # 3章だけを PDF に（html-c3 も同様）
$ make chapters   # 全章を個別の PDF/HTML に
$ make check      # 壊れた include・相互参照を検出
$ make clean      # 生成物を削除
----

生成物は `build/pdf/gail.pdf` と `build/html/gail.html` に出力される。`build/` は Git の管理対象外である。
`make clean` が消すのは PDF と HTML だけで、`build/fonts/` は残る。フォントを取り直すときは
`+./scripts/fetch-fonts.sh --force+` を使う。

== ディレクトリ構成

[source]
----
docs/
  index.adoc          全体をまとめる親文書
  _attributes.adoc    全文書共通の属性
  disclaimer.adoc     位置づけと免責事項（全体ビルドの冒頭に入る）
  c0/                 この試験について（前付け）
  c1/                 生成AIの基礎
  c2/                 Google Cloud の生成AI製品
  c3/                 出力の改善技法
  c4/                 ビジネス戦略と責任あるAI
  appendix/           付録A（用途からの逆引き）、付録B（GCP↔AWS 対比表）
scripts/
  build-pdf.sh        PDF を生成する
  build-html.sh       HTML を生成する
  fetch-fonts.sh      BIZ UDGothic を取得して build/fonts/ に配置する
  md2adoc.py          学習ノート（Markdown）から docs/ を再生成する
  unbreakable-tables.rb  表がページを跨いで分断されるのを防ぐ拡張
themes/               asciidoctor-pdf のテーマ
build/                生成物と取得したフォント（Git 管理外）
----

各章は `c*/index.adoc` が節ごとの `.adoc` を include する。節のファイル単体でもビルドできるが、
他章を参照する相互参照はリンクにならない。
