= 生成AIとは何か
include::../_attributes.adoc[]

[cols="1,5,5", options="header"]
|===
|  | 従来の機械学習 | 生成AI

| 出力 | 分類、予測、異常検出などの判断結果 | 文章、要約、会話応答、画像、プログラムコード
| 入力 | 特徴量に整形されたデータ | プロンプト（自然言語の指示）。画像・音声・動画などのデータも渡せる
| 学習 | 用途ごとにモデルを作る | 学習済みの基盤モデルを使う
|===

- 対比の軸は「新しいコンテンツを生成する」。要約・変換・抽出・対話も生成AIの守備範囲に入る。
- 「既存データを分類する」「数値を予測する」だけが目的なら従来の機械学習。

== 基盤モデル・LLM の特性

[cols="1,5", options="header"]
|===
| 観点 | 内容

| 定義 | パターンと関係を学習するために大量のデータでトレーニングされた複雑なアルゴリズム
| 学習データ | 大規模で多様（テキスト、画像、コード）
| 得意なこと | 幅広い言語とコンテキストの理解。多数のタスクへの適応
| 出力 | トレーニングデータの特徴を反映した新しいオリジナルコンテンツ
|===

外れる選択肢。

[cols="1,1", options="header"]
|===
| 選択肢 | 外れる理由

| 単一分野の高度に専門的なタスクに優れる | 強みは特化ではなく汎用性。専門特化はファインチューニング後の話
| 小さなデータセットから効果的に汎化する | 広範な能力には大量データが要る
| 追加のプロンプトなしで優れた論理的推論ができる | 基盤モデルは高度な数理・論理推論を保証しない。ハルシネーションの限界もある
| 物理デバイス／ユーザーインターフェース／ルールとガイドラインの集合 | いずれもモデルそのものではない
|===

- 推論を段階的にたどらせる Chain-of-Thought（<<chain-of-thought>>）は品質を上げる技法であって、推論能力を与えるものではない。
- 厳密な計算・確定的な判定は、モデルではなく従来のロジックや API に委ねる（<<rule-based-processing>>）。
