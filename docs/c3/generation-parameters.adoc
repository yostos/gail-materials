= 生成パラメータと安全性設定
include::../_attributes.adoc[]

[cols="1,4", options="header"]
|===
| 設定 | 制御するもの

| temperature | 出力のランダム性。低くすると決定的、高くすると多様になる
| topP | サンプリング対象を累積確率で絞る
| topK | サンプリング対象を上位K件に絞る
| maxOutputTokens | 生成する出力トークン数の上限。回答の長さを直接制御する
| SafetySetting | 有害コンテンツカテゴリごとの出力ブロック
|===

- プロンプトを変えずにモデル呼び出し側で出力を制御する設定。何を制御するかが設定ごとに違う。
- Google AI Studio ではブラウザ上で切り替えながら応答を比較できる。
- 出力の長さを抑える要件は `maxOutputTokens`（例: モバイルアプリで画面表示領域や通信量に制約があり、商品紹介文が長くなりすぎないようにする）。
- トークンは厳密にはバイト数ではないが、出力テキスト量を実用的に制限する主要な制御単位。

== 安全性設定

[cols="2,1", options="header"]
|===
| カテゴリ | 対象

| `HARM_CATEGORY_HATE_SPEECH` | ヘイトスピーチ
| `HARM_CATEGORY_DANGEROUS_CONTENT` | 危険な内容
| `HARM_CATEGORY_HARASSMENT` | ハラスメント
| `HARM_CATEGORY_SEXUALLY_EXPLICIT` | 性的に露骨な内容
|===

- しきい値（`HarmBlockThreshold`）は `BLOCK_LOW_AND_ABOVE`、`BLOCK_MEDIUM_AND_ABOVE`、`BLOCK_ONLY_HIGH` など。危険性の確率や重大度に応じてレスポンスをブロックする。

外れる選択肢。

[cols="1,3", options="header"]
|===
| 選択肢 | 外れる理由

| temperature / topK | 出力の一貫性を高めるだけ。安全性カテゴリの判定をしない
| maxOutputTokens | 回答量を制限するだけ。有害性を判定しない
|===
